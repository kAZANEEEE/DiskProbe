# DiskProbe · 软件星团

扫一个目录，把里面所有 `.exe` 揪出来，按**所在目录**堆成几条旋臂，用一张星系图给你看。

![开场](assets/海报_产品介绍.png)

---

## 先说结论

你的盘里到底装了些什么、散在哪、哪一堆最占地方——资源管理器答不上来。它只会按大小排一排文件。

这玩意儿答得上。它说：**1010 个 exe，分成了 29 堆，最大那堆是 Visual Studio 拖来的 153 个。**

- 平台：Windows 10 / 11
- 技术栈：Python 3.10+ / PySide6 / QPainter 自绘 / SQLite
- 版本：v0.1

## 怎么跑

**有 Python：**

```powershell
py -3 -m pip install PySide6-Essentials
py -3 ui.py
```

**没 Python：**

去 [Releases](https://github.com/kAZANEEEE/DiskProbe/releases) 下 `DiskProbe.exe`，双击。

> 没签名，第一次会被 SmartScreen 拦一下：「更多信息」→「仍要运行」。它不是病毒，只是没人给它交保护费。

## 怎么玩

1. 打开，等开场那 1.6 秒的乱码拼完（别跳过，我写的）
2. 点右下角 **选择目录以开始扫描**，挑个文件夹——**别选 `C:\`**，慢
3. 星星会一颗颗飞进来。**一颗星 = 一个 exe**，不是糊弄人的装饰
4. 扫完，星系按目录裂成若干条旋臂

| 你怎么动 | 它怎么应 |
|---|---|
| 滚轮 | 缩放 0.65×–1.6× |
| 双击空白 | 复位视角 |
| 拖动空白 | 转一圈，上下拖还能改倾角 |
| 悬停一条臂 | 这组浮起来，其余压暗 |
| 点一条臂 | 锁定它，**相机会自己转过去** |
| `Esc` | 取消锁定 |
| `←` `→` | 一组一组切 |
| 查看全部 N 个 → | 该组的完整清单，带目录列 |
| 搜索框 | 按路径过滤，命中的星亮着，其余暗下去 |

点侧栏那几个没做的（软件库 / 历史记录 / 分类管理 / 设置），**那个按钮会当场碎给你看**，然后飘一句「老子还没做」。

信我，这个反馈是真的爽。

「插件中心」里我藏了东西，自己点。

## 它老老实实的三条口径

这三条我写在这儿，是为了以后不糊弄人：

1. **一条旋臂 = 一个目录。**不是"一类软件"。判断"这是游戏还是开发工具"得读 exe 内部信息，那属于推断——宁可先说不知道。
2. **总大小只算 exe 本身**，不含同目录下的其他东西。
3. **扫不全就说扫不全。**回收站、`System Volume Information` 这种普通权限进不去的目录，界面上会直接写清有几个没读到。不装全知全能。

## 数据存哪

```
%LOCALAPPDATA%\DiskProbe\diskprobe.db
```

一个 SQLite 文件。删了不影响你原来任何一个文件，只是下次得重扫一遍。

## 想自己打包

```powershell
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --windowed --onefile ^
    --name DiskProbe ^
    --icon assets/logo.ico ^
    --add-data "assets;assets" ^
    --add-data "彩蛋.md;." ^
    ui.py
```

出来在 `dist\DiskProbe.exe`，43 MB。

> **踩过的坑，给你省一遍**：`--windowed` 打包之后 `sys.stdout` 是 `None`，代码里任何一句 `print()` 都会当场把程序干掉，而且**什么错误都不显示**。
> 这个项目运行路径里一行 print 都没有，所以安全。你要是往里加调试输出，记得先删。

## 里面长什么样

```
查盘工具/
├─ ui.py            界面，一大半是它（星图画布 / 面板 / 动效）
├─ scanner.py       扫描器：os.scandir 递归，带 on_file 回调
├─ storage.py       SQLite 存取
├─ classify.py      分组：按目录；读 exe 自带的厂商信息
├─ assets/          logo、海报、设置说明
├─ tests/           验收测试，纯脚本
├─ 踩坑记录.md      21+ 条真踩过的坑，含三组批处理编码血案
├─ 术语对照.md      每个英文标识符的中文对照
├─ 交互叙事闭环.md  动效系统规格（四幕 + token）
└─ 彩蛋.md
```

## 它是怎么来的

从一个小得不能再小的问题长出来的：**怎么在 Python 里把一棵目录树走完，还不被权限错误打断。**

`scanner.py` 里现在还留着大段第一人称的批注——当时为什么这么写、错在哪、后来怎么发现的。那些注释我不打算删，它们是这个项目的一部分，也是我们俩走过的路。

---

## 我知道它现在还不行的地方

- 只认 `.exe`，不认 `.dll` / `.msi` / 快捷方式
- 分组只看目录，不判断软件类别
- 没有扫描历史、不做前后变化对比（留给 v1.1）
- 星图对读屏软件不友好；键盘能用 `←` `→` `Esc`，但图形本身没有可访问名称
- 没有代码签名（所以才有那个 SmartScreen 提示）
