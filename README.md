# DiskProbe · 软件星团

扫一个目录，把里面的 exe 全找出来，按它们在哪个文件夹里分组，画成一片星系。

![预览](assets/海报_产品介绍.png)

---

## 为什么写这个

我 D 盘里有一千多个 exe。

想搞清楚都是些什么东西，资源管理器只能按大小排，排完还是不知道那一堆是哪来的。后来想想，我其实只想知道三件事：这些东西分成了几堆、哪堆最占地方、散在哪些文件夹里。

所以就写了这个。扫完之后它告诉我：1055 个 exe，31 堆，最大的一堆是 Visual Studio 拖来的 153 个。

- 平台：Windows 10 / 11
- Python 3.10+ / PySide6 / QPainter 自绘 / SQLite
- 当前版本：v0.2

## 怎么跑

**装了 Python：**

```powershell
py -3 -m pip install PySide6-Essentials
py -3 ui.py
```

**没装：**

去 [Releases](https://github.com/kAZANEEEE/DiskProbe/releases) 下 `DiskProbe.exe`，双击就行。

第一次会被 SmartScreen 拦一下，点「更多信息」→「仍要运行」。没签名，正常。

## 怎么用

1. 打开，等开场那 1.6 秒的乱码拼完
2. 点右下角「选择目录以开始扫描」，选个文件夹
3. 星星会一颗颗飞进来，一颗就是一个 exe
4. 扫完，星系按文件夹分成几条旋臂

**界面平时是空的。** 左边图例和右边面板只是淡淡的影子，鼠标移过去才浮出来；刚扫完会自己浮出来给你看 5 秒，然后让位给星空。

| 操作 | 效果 |
|---|---|
| 滚轮 | 缩放 |
| 双击空白 | 复位视角 |
| 拖动空白 | 旋转、上下拖改倾角 |
| 悬停一条臂 | 这组浮起来，其他压暗 |
| 点一条臂 | 锁定，相机会转过去 |
| `Esc` | 取消锁定 |
| `←` `→` | 一组一组切 |
| 查看全部 N 个 → | 完整清单，带目录列 |
| 搜索框 | 按路径过滤 |

左下角有个**留声机**。点一下，会随机浮出一句别人留下的话，先是一串乱码，再一个个定成真字。

侧栏那几个页面还没做。点它们，按钮会当场碎掉，然后飘一句「老子还没做」。

「插件中心」里藏了个东西。

## 几点说明

- **一条旋臂 = 一个文件夹**，不是「一类软件」。要判断这是游戏还是开发工具，得去读 exe 内部的信息，那是猜，我先不猜。
- **总大小只算 exe 本身**，不算同一个文件夹里的其他东西。
- **扫不全就说扫不全。** 回收站、System Volume Information 这些进不去的目录，界面上会写清有几个没读到。

## 数据在哪

```
%LOCALAPPDATA%\DiskProbe\diskprobe.db
```

一个 SQLite 文件。删了不影响你任何原始文件，只是下次要重扫。

留声机的留言在 `assets/voices.json`，加人只加一行：

```json
{"name": "谁", "words": "他说的话", "note": "身份"}
```

> 注意：数组里两个对象之间要有逗号，最后一个不要有。这是 JSON 最常踩的坑。

## 自己打包

```powershell
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --windowed --onefile ^
    --name DiskProbe --icon assets/logo.ico ^
    --add-data "assets;assets" --add-data "彩蛋.md;." ui.py
```

出来在 `dist\DiskProbe.exe`，43 MB。

两个坑记一下：

- `--windowed` 打包之后 `sys.stdout` 是 `None`，代码里任何一句 `print()` 都会让程序直接死掉，而且什么错误都不显示。这个项目运行路径里没有 print，所以是安全的。
- **资源路径不能写死绝对路径。** 打包后文件会解包到临时目录，得走 `sys._MEIPASS`——代码里是 `ui.py` 顶部的 `res()` 函数。

## 怎么来的

最开始只有一个问题：**怎么用 Python 把一棵目录树走完，还不被权限错误打断。**

`scanner.py` 里留着很多第一人称的注释，写的是当时为什么这么写、哪里错了、后来怎么发现的。那些不删，本来就是这个项目的一部分。
