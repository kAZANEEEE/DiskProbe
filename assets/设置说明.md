# 设置与说明

## 这个工具在做什么

DiskProbe 扫描一个目录，把里面所有 `.exe` 找出来，按**所在目录**分组，用一个星系图展示。

## 扫描口径（重要）

- **扇区 = 分组**，每组对应一个目录。臂的长度和粗细按该组 EXE 数量决定。
- **粒子 = 文件**，一颗星就是一个 EXE。扫描时一颗颗飞进来，不是装饰。
- **总大小**只统计 EXE 本身，不含同目录下的其他文件。
- 「已扫描目录」= 实际找到 EXE 的目录数，不是扫过的目录总数。

## 数据放在哪

```
%LOCALAPPDATA%\DiskProbe\diskprobe.db
```

一个 SQLite 文件。删掉它不会影响任何原始文件，只是下次要重扫。

## 键盘与鼠标

| 操作 | 效果 |
|---|---|
| 滚轮 | 缩放星图（0.65×–1.6×） |
| 双击空白 | 复位视角与缩放 |
| 拖动空白 | 旋转 / 上下拖动改倾角 |
| 点击臂 | 锁定该分组，相机转向它 |
| `Esc` | 取消选中，面板与浮层退出 |
| `←` `→` | 在分组之间切换 |

## 已知限制

- **扫描不完整时会有提示**：某些系统目录（回收站、System Volume Information）普通权限读不进去，界面上会明确写出数量，不会假装扫全了。
- **分组依据是目录，不是软件类别**。判断「这是游戏还是开发工具」需要阅读 EXE 的内部信息，那属于推断，暂不做——宁可先说不知道。
- 列表中同名文件很多是正常的（比如一堆 `python.exe`），看「目录」列区分。

## 节能模式

打开后停止所有位移动画，只保留颜色变化。窗口失焦时动画本来就会暂停，扫描线程不受影响，照样跑完。
